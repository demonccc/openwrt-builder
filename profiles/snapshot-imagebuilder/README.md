# Snapshot ImageBuilder build

Builds a current OpenWrt snapshot image using the official prebuilt ImageBuilder.

- Method: `imagebuilder`
- Target: `x86/64`
- Device: `generic`
- Source: official OpenWrt snapshot ImageBuilder

This profile is a generic base for fast snapshot image assembly using packages already published by OpenWrt.

See the [profile reference](../../docs/profiles.md) for ImageBuilder behavior and profile file semantics.
